# Proyecto Clase 07

Proyecto desarrollado durante el Técnico en Programación de Software del SENA.

## Objetivo
Demostrar el uso de prácticas de control de versiones con Git y GitHub mediante el desarrollo de una aplicación web modular en PHP que incluye funcionalidades como la gestión de usuarios, estilos CSS dinámicos y módulos de consulta de clima y recetas.

## Tecnologías
- HTML
- CSS
- PHP (aplicado en backend y lógica del servidor)
- Git y GitHub

## Cómo ejecutar
1. Clonar el repositorio o descargar los archivos del proyecto.
2. Mover la carpeta del proyecto a la ruta raíz de tu servidor local (por ejemplo, `htdocs` en XAMPP o `www` en WampServer).
3. Iniciar los servicios de Apache desde el panel de control del servidor local.
4. Abrir el navegador web e ingresar a la dirección URL: `http://localhost/clase07/index.php`.
